# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in wc2026, please report it responsibly via
email to **security@shovalbenjer.com** or open a private security advisory on GitHub.

Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We aim to acknowledge reports within 5 business days and will provide a timeline for
a fix once the issue is confirmed. We appreciate your help in keeping the project
and its users secure.
