# matchiq gambles site (GitHub Pages)

Static, self-contained page generated by `scripts/build_site.py`.

- `index.html` — the page (prediction data embedded; opens locally via file:// too)
- `data.json` — machine-readable predictions (winner, top scorer, group fixtures)

Regenerate: `python scripts/build_site.py --paths 50000`

Enable hosting under **Settings → Pages → Source: GitHub Actions** (see `.github/workflows/pages.yml`).
